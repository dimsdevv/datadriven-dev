# ⚡ Data-Driven Dev Blueprint

> A structured 4-month learning roadmap and engineering lab for Information Systems undergraduate studies (Semester 4).  
> Bridging **Modern Software Engineering (Laravel & JavaScript)** with **Data Analytics & Business Intelligence (MySQL & Financial Metrics)**.

---

## 🧭 Repository Structure

This repository is organized following clean architectural separation:

```text
.
├── docs/                      # Learning roadmap, architecture specs & diagrams
│   └── roadmap.md             # Complete 4-month weekly breakdown
├── 01-foundations/            # Month 1: PHP OOP, Modern JS (DOM/Fetch), Native PDO
├── 02-laravel-core/           # Month 2: Laravel MVC, Migrations, Eloquent ORM
├── 03-business-analytics/     # Month 3: Advanced SQL, Views, Stored Procs, Chart.js
└── 04-capstone-retailiq/       # Month 4: Capstone Enterprise POS & Analytics (Clean Architecture)
```

---

## 🎯 Core Competencies & Goals

1. **The Builder:** Developing clean, maintainable web applications using PHP (Laravel) and modern JavaScript.
2. **The Analyst:** Translating real-world business metrics (Revenue, Gross Margin, MoM Growth) into optimized SQL queries.
3. **The Architect:** Applying Clean Architecture principles (Domain, Use Cases, Infrastructure, Presentation) to avoid fat controllers and messy codebases.
